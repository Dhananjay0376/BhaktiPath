## 📖 About

BhaktiPath is a web application designed to help devotees discover temples and plan their pilgrimage routes. Whether you're looking for ancient temples, specific deities, or planning a spiritual journey, BhaktiPath makes it easy to find and explore sacred destinations.

## ✨ Features

- 🔍 **Temple Search**: Search for temples by name, location, or deity
- 📍 **Location-Based Discovery**: Find temples near you
- 🗺️ **Pilgrimage Planning**: Plan multi-temple visits and routes
- 📱 **Responsive Design**: Works seamlessly on mobile and desktop
- 🕉️ **Detailed Information**: Get temple history, timings, and visiting guidelines

## 🛠️ Tech Stack

- **Frontend**: TypeScript, HTML, CSS
- **Deployment**: Netlify (Continuous Deployment)
- **Development**: Built using Antigravity (Google's IDE)
- **Version Control**: Git & GitHub

## 💻 Installation & Setup

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Steps

```bash
# Clone the repository
git clone https://github.com/Dhananjay0376/BhaktiPath.git

# Navigate to project directory
cd BhaktiPath

# Install dependencies
npm install

# Start development server
npm start
```

The application will open at `http://localhost:3000`
